# Zaelion — 2026-09-09

## Decisões tomadas

- **Stack padrão da squad confirmada sem ajuste estrutural**: Next.js 15 App Router + TS strict + Tailwind v4 (`@theme`) + shadcn/ui + Motion + pnpm. Registrada em [[../project/tech-stack]].
- **Sem `output: 'export'`** — export estático desligaria a otimização do `next/image`, e o site é pesado em fotografia. Mudar exige ADR.
- **Princípio arquitetural: "conteúdo é dado, não markup"** — todo fato do clube vive em `src/content/*.ts` tipado. Permite que research corrija fato sem tocar layout e que UX mude layout sem tocar fato.
- **5 rotas**: `/`, `/historia`, `/titulos`, `/estadio`, `/elenco`. Sem `/contato` — contato e redes sociais vivem no footer global.
- **`/elenco` é estático e explicitamente ilustrativo** (aviso visível ao usuário), já que não há backend nem fonte de dados de plantel.
