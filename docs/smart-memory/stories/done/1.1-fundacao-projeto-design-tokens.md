# Story 1.1: Fundação do projeto e design tokens

## Contexto

O repositório está vazio. Nenhuma outra story pode começar sem o projeto Next.js instalado, os tokens de marca do Galo declarados e o root layout de pé. Esta story cria a base sobre a qual todas as demais se apoiam — e por isso toca dois God Nodes (`app/layout.tsx` e `app/globals.css`).

## Acceptance Criteria

- [x] AC1 — `pnpm dev` sobe o projeto sem erro e `pnpm build` conclui com sucesso, gerando `/` como rota **estática** (`○` no output do build).
- [x] AC2 — TypeScript em `strict: true`; `pnpm lint` passa sem erro nem warning.
- [x] AC3 — Tailwind v4 instalado com `@import "tailwindcss"` em `src/app/globals.css`. **Não existe `tailwind.config.ts`** no repositório.
- [x] AC4 — Bloco `@theme` em `globals.css` declara, no mínimo: `--color-background`, `--color-foreground`, `--color-primary`, `--color-primary-foreground`, `--color-accent`, `--color-muted`, `--color-border`, `--font-sans`, `--font-display`, `--radius-lg/md/sm`. Valores derivados de `docs/smart-memory/agents/ux/` quando disponíveis; caso contrário, paleta preto/branco do clube com `// TODO(ux)` sinalizado.
- [x] AC5 — Nenhum valor de cor hex/rgb hardcoded em componente. Verificável: busca por `#` seguido de 3/6 hex em `src/components/` e `src/app/*.tsx` retorna zero ocorrências.
- [x] AC6 — Utility `container-site` definida via `@utility` e aplicável (`<div class="container-site">` centraliza com max-width e padding lateral).
- [x] AC7 — `src/app/layout.tsx` define `<html lang="pt-BR">`, fontes via `next/font` (`display: swap`) e `metadata` base com `title.template`, `description` e `metadataBase`.
- [x] AC8 — shadcn/ui inicializado e os componentes `button card badge separator sheet navigation-menu tabs avatar` presentes em `src/components/ui/`.
- [x] AC9 — `motion` e `lucide-react` instalados; `src/lib/utils.ts` exporta `cn()`.
- [x] AC10 — Alias `@/*` resolve para `src/*` no `tsconfig.json`.

- `create-next-app` com TypeScript, App Router, Tailwind, `src/`, alias `@/*`, pnpm

**OUT:**

## Notas técnicas

Stack e versões fechadas em [[../../project/tech-stack]]; estrutura de pastas em [[../../project/architecture]].

- Tailwind **v4 é CSS-first**: tokens só no `@theme`, nunca em arquivo de config JS.
- Usar duas famílias: `--font-sans` para corpo e `--font-display` para títulos/números de destaque (placar, ano, contagem de títulos). Ambas via `next/font` com variável CSS.
- **Não usar `output: 'export'`** no `next.config` — decisão registrada no tech-stack.
- Paleta do Galo é preto e branco: atenção redobrada a contraste. Definir `--color-foreground` e `--color-background` de modo que o par atinja AA (≥ 4.5:1) nos dois sentidos.
- Consultar `docs/smart-memory/agents/ux/` antes de fechar valores de token. Se o UX ainda não publicou, marcar `TODO(ux)` e seguir — não bloquear.
