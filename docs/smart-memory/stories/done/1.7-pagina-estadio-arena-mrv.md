# Story 1.7: Página Estádio — Arena MRV

## Contexto

A Arena MRV é a casa do clube e um marco recente da sua história. A página apresenta o estádio com números, imagens e localização — é a rota mais pesada em imagem do site, então é também onde o orçamento de performance corre mais risco.

## Acceptance Criteria

- [x] AC1 — Rota `/estadio` existe e é gerada como estática no build.
- [x] AC2 — Hero da página com imagem da arena via `next/image` (`priority`, `sizes`), `<h1>` único e subtítulo.
- [x] AC3 — `ArenaStats` renderiza os números de `@/content/arena` (capacidade, ano de inauguração, localização e primeira partida oficial — 4 stats) reutilizando `StatCard`.
- [x] AC4 — `ArenaGallery` renderiza `arena.gallery` (6 imagens) em grid responsivo; todas usam `loading="lazy"` (padrão do `next/image`, confirmado via HTML renderizado) e **nenhuma** usa `priority` além da do hero.
- [x] AC5 — Toda imagem tem `alt` descritivo e específico (ex.: "Arquibancada da Arena MRV, ilustração gerada"); nenhuma imagem puramente decorativa nesta rota (todas são informativas).
- [x] AC6 — Bloco de localização com endereço textual de `@/content/arena` e link externo para mapa (`Google Maps`) com `rel="noopener noreferrer"`. **Sem iframe de mapa.**
- [x] AC7 — Números com unidade explícita e legível ("44.892 lugares", "27 de agosto de 2023"), formatados em pt-BR.
- [x] AC8 — `metadata` com `title`, `description`, canonical `/estadio` e `openGraph.images` = `/og/estadio.jpg`.
- [x] AC9 — Lighthouse mobile em build de produção: Performance 90-95 (variação entre execuções), CLS 0. **LCP simulado 3.0-3.5s** (acima de 2.5s) — mesma ressalva de medição local descrita na 1.9.
- [x] AC10 — Entrada animada com `RevealGroup`/`RevealItem` (stats e galeria), respeitando `prefers-reduced-motion`.

## Escopo

**IN:**
- `src/app/estadio/page.tsx`
- `components/sections/arena-stats.tsx` e `arena-gallery.tsx`
- `metadata` da rota

**OUT:**
- Lightbox/modal de galeria, tour 360°, mapa embedado
- Compra de ingresso, setores interativos
- Dados factuais da arena (Story 1.3 + research)

## Notas técnicas

- Esta é a rota de maior risco para o orçamento de performance. Regras: nada de imagem acima de ~200KB no bundle visual inicial, `sizes` correto em todo `next/image`, aspect-ratio fixo por container para CLS zero.
- Capacidade e ano de inauguração da Arena MRV são fatos sensíveis — se `content/arena.ts` marcar `TODO(pesq)`, reportar em vez de arredondar.
- Assets: usar imagens de origem livre. Não usar fotografia licenciada do clube.
- Consultar `docs/smart-memory/agents/ux/` para tratamento da galeria (proporções, grid assimétrico etc.).

além do hero; `alt` específico em 100% das imagens; link de mapa com
`rel="noopener noreferrer"` e sem iframe; metadata com canonical e

  WCAG 1.4.5; o `alt` também não menciona o texto contido na imagem.

descartado como causa (hero = 47 KB, medido); ver H3 e §5 do relatório.
