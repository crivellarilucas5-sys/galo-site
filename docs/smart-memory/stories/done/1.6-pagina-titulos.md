# Story 1.6: Página Títulos — conquistas do clube

## Contexto

A galeria de conquistas é a página de maior valor de "prova" do site e o destino do bloco de destaques da Home. Precisa ser precisa nos números e legível de relance — o torcedor vem contar taça, não ler parágrafo.

## Acceptance Criteria

- [x] AC1 — Rota `/titulos` existe e é gerada como estática no build.
- [x] AC2 — Bloco de resumo no topo com `StatCard`s exibindo total geral e totais por tier, **todos calculados em runtime a partir de `@/content/trophies`** via `lib/trophies.ts` (`totalTrophies`/`totalByTier`, somando o campo `count`) — nenhum total digitado à mão.
- [x] AC3 — Conquistas agrupadas em três seções na ordem: Internacionais → Nacionais → Estaduais, cada uma com `<h2>` (via `groupByTier`, que omite tiers vazios).
- [x] AC4 — Cada conquista é um `Card` com nome da competição, número de títulos em destaque (`font-display`) e a lista de anos (ou `periodLabel` quando os anos individuais não são todos conhecidos — ver nota de conteúdo na 1.3).
- [x] AC5 — Uma competição sem nenhum título no dataset não renderiza card vazio; um tier sem conquistas não renderiza a seção (`groupByTier` filtra tiers vazios).
- [x] AC6 — Grid responsivo `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3` com `gap-4 md:gap-6`.
- [x] AC7 — Entrada animada com `RevealGroup`/`RevealItem`, respeitando `prefers-reduced-motion`.
- [x] AC8 — `metadata` com `title`, `description` e canonical `/titulos`.
- [x] AC9 — Anos legíveis por leitor de tela como lista (`<ul><li>` por ano); quando não há lista individual, texto explícito "Período: 1915–2025".
- [x] AC10 — Lighthouse a11y = 100 na rota (build de produção); contraste AA — o acento dourado nunca é usado como texto corrido, só como ícone/número de destaque sobre `bg-surface` escuro.

## Escopo

**IN:**
- `src/app/titulos/page.tsx`
- `components/sections/trophy-grid.tsx`
- Reuso de `StatCard` e `SectionHeading`
- `metadata` da rota

**OUT:**
- Filtros interativos, ordenação, busca
- Página de detalhe por conquista
- Correção/validação dos fatos (responsabilidade de 1.3 + research)

## Notas técnicas

- Agregação por tier deve ser função pura no topo da página (ou em `lib/`), fácil de conferir. Não espalhar `reduce` dentro do JSX.
- Números de conquistas são o ponto mais sensível a erro factual do site inteiro: se `content/trophies.ts` trouxer `TODO(pesq)`, registrar a pendência no Dev Agent Record e sinalizar ao lead — **não publicar número inventado como se fosse confirmado**.
- `TrophyGrid` recebe `trophies` por props (componente burro), a página faz o agrupamento.
- Consultar `docs/smart-memory/agents/ux/` para tratamento visual de taça/ícone e `agents/research/` para conferência dos anos.
