# Story 1.5: Página História — linha do tempo

## Contexto

A história é o ativo emocional central de um site de torcedor. Esta página conta a trajetória do clube de 1908 até hoje em formato de linha do tempo navegável, sendo o destino do CTA principal do hero da Home.

## Acceptance Criteria

- [x] AC1 — Rota `/historia` existe e é gerada como estática no build.
- [x] AC2 — `<h1>` único da página; cada marco da timeline usa `<h3>` (sob um `<h2 className="sr-only">` de seção), sem pular níveis.
- [x] AC3 — `Timeline` renderiza **todos** os eventos de `@/content/timeline` — nenhum evento hardcoded no componente; adicionar item no array o faz aparecer.
- [x] AC4 — Layout responsivo: em mobile a linha é vertical alinhada à esquerda; em `lg+` alterna lados (esquerda/direita) em torno do eixo central (grid `[1fr_2rem_1fr]`).
- [x] AC5 — Cada marco exibe ano em destaque (`font-display`), título, descrição e imagem opcional via `next/image` com `alt` descritivo.
- [x] AC6 — Entrada de cada marco animada com `RevealGroup`/`RevealItem` (stagger), respeitando `prefers-reduced-motion`; `viewport={{ once: true }}`.
- [x] AC7 — Semântica de lista: a timeline é `<ol>`/`<li>` (é sequência ordenada), não uma pilha de `<div>`.
- [x] AC8 — `metadata` da rota com `title`, `description` e `alternates.canonical` para `/historia`.
- [x] AC9 — Sem CLS ao carregar imagens (`next/image` com `fill` + container `aspect-[4/3]`); Lighthouse a11y = 100, CLS = 0 na rota (build de produção).

## Escopo

**IN:**
- `src/app/historia/page.tsx`
- `components/sections/timeline.tsx`
- `metadata` da rota

**OUT:**
- Filtro por década, busca, navegação por âncora lateral (pode virar story futura)
- Página de detalhe por marco
- Edição do conteúdo factual da timeline (isso é Story 1.3 + research)

## Notas técnicas

- Os dados já chegam ordenados de `content/timeline.ts` (AC6 da Story 1.3) — não reordenar na página.
- Se algum marco vier com `// TODO(pesq)`, renderizar normalmente mas **não** exibir marcação de TODO ao usuário; reportar a pendência no Dev Agent Record.
- A linha central pode ser um pseudo-elemento/borda; evitar `position: absolute` que quebre em zoom 200%.
- Verificar `docs/smart-memory/agents/research/` para riqueza de descrição e `docs/smart-memory/agents/ux/` para tratamento visual da linha e dos anos.
